# Smritika — Sunlit Modular · NE India Cognitive Care App

## Aesthetic Stance
Sunlit Modular adapted for North East India cultural warmth. Asymmetric modular panels, large pale-butter content cards balanced by compact cobalt navigation. Warm ivory ground with terracotta and bamboo-green cultural accents layered over the base palette.

## Color Tokens
| Token | Value | Use |
|---|---|---|
| Background | #FBF8F0 | Page ground, warm ivory |
| Butter panel | #F1E3A4 | Primary content panels |
| Navy | #1D2B49 | Headings, structural text |
| Cobalt | #355FC7 | Navigation, primary actions |
| Terracotta | #C4622D | Cultural accent, warmth cues |
| Bamboo green | #4A7C59 | Secondary accent |
| Sand | #EFE0C8 | Card surfaces |
| White | #FFFFFF | Inner card surfaces |

## Typography
- **Heading**: Nunito 700–800, 24–32px — round, warm, highly legible for elderly users
- **Body**: Nunito 400–600, 18–20px minimum — never below 18px
- **Label/UI**: DM Sans 500–600, 14–16px
- Base font size: 20px (1.25rem)

## Spacing & Shape
- Touch targets: minimum 64px height
- Border radius: 16px cards, 12px buttons, 999px pill badges
- Grid: single-column stacked cards on mobile; generous 20–24px gaps
- Padding: 20–24px horizontal page padding

## Imagery
- Cultural icons: bamboo motifs, woven textile patterns as subtle textures
- Friendly AI avatar illustration (warm, non-clinical)
- Unsplash documentary photos for article cards

## Voice Assistant
- Mic button: 72px diameter, cobalt fill, always visible in header
- Pulse animation when active
- High-contrast white mic icon on cobalt

## Accessibility
- All text ≥ AA contrast (4.5:1)
- Touch targets ≥ 64px
- Color never the sole affordance indicator
- Font size never below 18px
